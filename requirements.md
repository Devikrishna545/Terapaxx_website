## Functional Requirements
1. Route-compatible static pages: /, /about/, /gallery/, /contact-us/, /products/ and /home redirect support.
2. Sticky responsive header with mobile navigation and active-link highlight.
3. Hero section with clear enterprise positioning and CTA buttons.
4. Services section listing Project Management, Contracting, Solutions, Marketing.
5. About content preserving company mission, vision, and service model.
6. Gallery with responsive grid and keyboard-closable lightbox modal.
7. Contact page with company address, phone, email, social links, and web form.
8. Web form submission via Web3Forms endpoint, with user feedback states.
9. Footer with quick links and company contact references.
10. Existing business information from live website retained in the new IA.

## Non-Functional Requirements
1. Mobile-first responsive UI from 320px to widescreen layouts.
2. Works on recent Chrome, Safari, Firefox, Edge plus mobile browsers.
3. Semantic HTML and WCAG-minded accessibility basics.
4. Performance-oriented image and JS loading strategy.
5. SEO-friendly metadata, Open Graph, sitemap, robots, canonical URLs.
6. Clean static structure for low-maintenance CloudDexter deployment.
7. Safe deployment with backup, staging, and rollback path.

## Acceptance Checks
1. Navigation, gallery, and contact form behaviors work without framework dependencies.
2. Pages are readable and usable on mobile and desktop.
3. Web3Forms submissions reach the configured inbox.
4. No broken links across internal pages.
5. Redirect for /home route behaves correctly.
