## Build Instructions
1. Use HTML5 + Tailwind CSS CDN + vanilla JavaScript only.
2. Preserve existing business information unless explicitly approved otherwise.
3. Keep route compatibility for current public URLs.
4. Prefer lightweight, maintainable code with reusable UI sections.

## QA Instructions
1. Validate mobile and desktop responsiveness before deployment.
2. Validate keyboard navigation and focus visibility.
3. Validate page metadata and Open Graph tags.
4. Validate Web3Forms submission and error handling.
5. Validate gallery modal behavior on touch and keyboard.

## Deployment Instructions (CloudDexter)
1. Upload first to staging folder and verify all pages.
2. Keep a backup of current live site before cutover.
3. Promote staging to domain document root after sign-off.
4. Keep rollback folder until post-launch stabilization.
5. Ensure HTTPS is active and redirects are correct.
